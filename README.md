# 🛒 E-commerce Website

Welcome to **E-commerce-Website**, a modern and responsive e-commerce web application built with React! This project showcases a fully functional online store where users can browse products, filter them, view product details, and manage their shopping cart. 🚀

---

## 🌟 Features

- **Responsive Design** 📱💻: Fully optimized for desktop and mobile devices.
- **Product Listing** 🏷️: Browse a variety of products with images, prices, and ratings.
- **Search & Filters** 🔍: Easily search for products and filter by price, brand, or category.
- **Shopping Cart** 🛒: Add, remove, and view items in your cart with a real-time total price calculation.
- **Product Details** 📦: View detailed information about each product.
- **Dynamic Routing** 🔀: Navigate seamlessly between pages using React Router.

---

## 🛠️ Tech Stack

- **Frontend** 🎨: React, TypeScript, TailwindCSS
- **State Management** 🔄: State management using Zustand
- **Icons** 🔲: React Icons for a modern UI
- **Routing** 🚦: React Router for dynamic navigation

---

## 🚀 Getting Started

Follow these steps to run the project locally:

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/BossNattawat/E-commerce-Website.git
   ```

2. Navigate to the project folder:

    ```bash
    cd E-commerce-Website
    ```

3. Install dependencies:

    ```bash
    npm install
    ```

4. Start the development server:

    ```bash
    npm run dev
    ```
